# CV Analyzer for Igor Pro

Version: **0.0.1**

BioLogic EC-Lab の通常 CV (`.mpt`) を読み込み、サイクルごとの電流–電位曲線と集計表を作るマクロです。Igor Pro 8 以降を想定しています。**現時点では Igor でのコンパイル・実行を確認できていない試作版です。**

## 使い方

1. Igor Pro で **File → Open File → Procedure** から `CVAnalyzer.ipf` を開き、Compile します。
2. **Macros → CV Analyzer** を選びます。
3. 通常 CV の酸化開始または還元開始を選択し、**MPT ファイルを選択して解析** からファイルを選びます。選択は記録用で、通常 CV の計算は共通です。開始方向の自動判定はしません。
4. グラフと集計表が開き、読み込んだ波形は `root:CVAnalyzer:<ファイル名>` にファイルごとに保存されます。実験ファイルを保存すると結果も保存できます。

酸化側・還元側 stepwise は選択肢のみで、実装されていません。選択して読み込みを実行すると説明を表示して中止します。

## 集計の定義

- EC-Lab の `cycle number` でデータを分け、測定電位 `Ewe/V` と電流 `<I>/mA` をそのままプロットします。電位基準の変換はしません。
- 各サイクルの電位の最大・最小、電流の最大・最小とその電位、点数、時間幅を出します。電流極値は生データの最大・最小であり、ベースライン補正したピークではありません。
- 正負の電荷量は `time/s` に対する電流の台形積分で、単位は mAh。符号が変わる区間は線形補間して分割します。負電荷は負の値です。サイクル番号が変わる点の間の区間は積分に含めません。電流の符号と走査方向は同義ではありません。
- 部分サイクルもファイルの番号どおり集計します。電極面積・質量による正規化、平滑化、ベースライン補正、サイクル完結判定は行いません。

必須列の欠落、数値不正、時間やサイクル番号の逆行、短いデータ、形式違いを検出した場合は読み込みを中止します。すべての EC-Lab バージョンや形式での動作は未確認です。エラー列の内容や測定器の過負荷の有無は確認していません。

添付試料は独立にテキストとして確認し、10,813 行、サイクル 1–3 であることを確認しました。添付画像の例とは電位範囲が異なり、データの最大電位は約 3.60 V です。

## グラフ表示

プロット領域は絶対サイズで横 8 cm × 縦 6 cm、表示倍率は 2 倍です。基本文字サイズは 12 pt、軸ラベルは 14 pt。軸ラベルは Cell Voltage V / V と Current I / mA です。変数記号は斜体です。電位の参照電極は入力ファイルの測定条件を確認してください。余白は左 56、下 39、右 14、上 14 pt です。各軸は Igor の自動スケール範囲の両端に、その幅の 15% を追加します。凡例は背景透明・枠なしです。パネルと集計表を左、グラフを右に配置します。画面が小さい場合や複数ファイルを続けて開いた場合は、画面外や既存ウィンドウとの重なりが生じる可能性があります。

## フォルダ名と wave Note

データフォルダは拡張子を除いたファイル名を基にし、先頭が数字なら `A` を付けます。Igor の名前に使えない文字は変換し、同名のフォルダがあれば上書きせず別名を付けます。

サイクル別の電位・電流 wave の Note に元ファイル名、EC-Lab の cycle number、元 MPT 内の開始行と終了行を記録します。行番号はヘッダーを含む 1 始まりで、両端を含みます。全サイクルを含む元データ・集計 wave の Note には、各サイクルの行範囲を列記します。`source_line` wave は各測定点の元ファイル行を保持します。凡例は図の右下に配置し、ファイル内のサイクル番号を 1st、2nd、3rd … と表示します。

サイクル別の線色は参考マクロの InoColors と同じ先頭 10 色を使い、11 サイクル目から繰り返します。色設定はこのマクロ内にあり、参考マクロの読み込みは不要です。

## 2 接線の交点フィット（試作）

CV Analyzer パネルの **2接線フィッティングを開く** を押し、対象グラフを選択します。選択した CV グラフの真下に開くフィット用グラフでは、対象サイクルを凡例ではなく右下の注記として表示し、波形に CV グラフと同じ色を使います。A–B と C–D を同じ走査枝の実測波形上に配置し、サイクルと酸化側・還元側をセレクトボックスで切り替え、「計算・保存」を押します。各サイクル・各側のカーソル位置と保存済み結果は独立して保持され、切り替えて戻ったときに復元されます。元の Igor 実験を保存すれば状態も保存されます。各範囲は両端を含む 3 点以上で、測定点の順序に基づきます。フィット結果は選択した範囲に依存します。

選択した 2 範囲の最初の点から最後の点まで、電位の増減方向が変わる場合は拒否します。測定ノイズによる微小な反転も拒否する保守的な判定です。交点がいずれかの範囲の外にある場合は、表に外挿を示します。カーソル移動後はグラフ上の直近の計算結果を無効にします。グラフ内の表は同じ測定ファイルの全サイクルを行とし、酸化・還元の最後に保存した電位を別々の列に保持し、外挿の場合は `*` を付けます。表の値は保存済みの結果であり、現在のカーソル範囲を示すものではありません。保存後にカーソルを動かした場合は、切り替えて戻っても以前のフィット線を現在の結果として表示しません。同じ側の再計算でそのセルを更新します。酸化・還元はユーザーが選ぶラベルであり、自動判別しません。結果 wave `CVA_ox_*` と `CVA_red_*` の Note には元ファイル、サイクル、選択した側、各カーソルの元行、傾き・切片、交点と外挿の有無を記録します。電位基準の変換は行いません。

画面の高さによってはフィット用ウィンドウの一部が画面外に配置されることがあります。

この機能は Igor Pro 上のコンパイル、カーソル操作、実データでの結果確認がまだ完了していません。検証が済むまで数値の判断には使用しないでください。
